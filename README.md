# Pygame Projekt: [WHACK A ...]

Dies ist ein Pygame-Projekt, das im Rahmen vom Modul "Programmieren" im WS25/26 erstellt wurde. Ziel des Spiels ist es, rechtzeitig verschiedene Charaktere mit dem Mauszeiger zu treffen, um den Score zu erhöhen.

## 🎮 Spielstart

Um das Spiel zu starten, folge diesen Schritten:

1. Stelle sicher, dass Python installiert ist.
2. Installiere die benötigte Bibliothek (Pygame):
   `pip install pygame`
3. Stelle sicher, dass alle benötigten Dateien (Sounds, Sticker, Themes, etc.) im Projektordner sind.
4. Starte das Spiel über die Hauptdatei:
   `python main.py`

Die Steuerung erfolgt komplett über die Maus. Um das Spiel zu beenden, gehe ins Menü (LEERTASTE während des Spiels) und dann ESC.

## 📂 Projektstruktur

* `main.py` - Die Startdatei des Spiels. Hier wird die Game-Loop ausgeführt.
* `assets/` - Alle Grafiken, Sounds und Schriftarten.
